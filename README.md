# freeCodeCamp Arabic — AI & Machine Learning

A practical collection of Python, Machine Learning, Deep Learning, Transformers, Hugging Face, Diffusion Models, and AI deployment tutorials.

The repository is designed to connect **theory with hands-on implementation** through Jupyter Notebooks.

## Topics

- Python
- NumPy & Pandas
- Matplotlib
- Scikit-learn
- PyTorch
- Transformers
- Hugging Face
- Diffusion Models
- Audio & Video Models
- Gradio
- Model Deployment
